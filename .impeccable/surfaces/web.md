# Race Week dashboard (web/)

Mode: Operate. A recruiter or fan reads one race weekend's predictions against what happened.

## Direction contract

THESIS: The weekend is a paddock credential: the zones cleared are the sessions the model has seen. Refuses the dark broadcast-card grid every F1 dashboard ships.

OWN-WORLD: Matte laminate ground (#F3F4F1), engraving ink, one ultramarine role band (#2337E6) reserved for the model's prediction and the credential band. Marshal-flag state colours: yellow SC, black/yellow VSC, red flag. Archivo variable: 62–68% width heavy for numerals and heads, 100% for text. Square corners, 1px rules, ink header strips, rubber-stamp state marks, run id as barcode.

STORY: Who did the model favour, did it come true, how was the model built; then risk, tyres, conditions, context.

FIRST VIEWPORT: Ultramarine credential band: event name, circuit, countdown/FINISHED, barcode run id; a six-zone access strip (numbered stages, cleared filled, viewed punched). Under it the verdict line (favourite, score, WON/LOST stamp) with the scorecard, then finishing order and race-control risk.

FORM: Paddock Credential, position 7 of 7 on the grounded list. seed: none (the roll printed no SEED REFERENCE line)

Raises: orienteering (ultramarine only for prediction), ticket wallet (states stamp), vertical feed (one answer owns the first viewport), lexicon (rank by apparatus).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
